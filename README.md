# [Technomart](https://landing-page-technomart.netlify.app/)

Landing page for Technomart store


## Features

- Chapters carousel
- Hidden menu
- Modal feedback
- Modal map
- Hover menu
- Mobile layout

## Tech Stack

- Typescript
- Sass
- Vite
- Eslint
- Prettier
- Normalize.css

## How to use


1. Clone the repo

```bash
git clone https://github.com/SavitskayaKseniya22/landing-page-technomart.git
```

2. Install dependencies

```bash
npm ci
```

3. Start the dev server

```bash
npm start
```
